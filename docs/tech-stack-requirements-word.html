№ Требование к стеку Технология / средство (проект) Назначение и примечание
1 Клиентское приложение — одностраничное (SPA), модульная сборка React 19, Vite 6, Framer Motion 12.x Компонентный UI; анимации переходов; сборка production-бандла
2 Маршрутизация на клиенте без перезагрузки страницы react-router-dom 7.x (HashRouter) Разделы: матчи, таблица, профиль, статистика матча, аккаунт, админ

5 Сервер приложений — REST-прокси к внешнему API, скрытие ключей от браузера Python 3, Flask ≥ 2.0, flask-cors Эндпоинты /api/livescore/rpl/*; CORS при раздельном запуске фронта и бэка

7 Интеграция с поставщиком данных о матчах LiveScore API (через livescore_api.py) Источник live-матчей, расписания, таблицы, статистики матча
8 Дополнительно: опциональная оболочка под мобильную платформу Capacitor 8.x (Android) Сборка build:capacitor при необходимости нативного контейнера
9 Статический анализ и качество кода фронтенда ESLint 9.x, плагины React Команда npm run lint в каталоге football-stats/
